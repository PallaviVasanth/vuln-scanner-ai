\# Security Policy



\## Reporting a Vulnerability



Please do not report security vulnerabilities through public GitHub issues.



Please include:



\- A description of the vulnerability

\- Steps to reproduce it

\- Potential impact

\- Relevant evidence



Security reports will be reviewed and investigated.



\## Supported Version



The latest version on the default branch is the primary maintained version.



\## Responsible Disclosure



Please allow reasonable time for a security issue to be investigated before publicly disclosing technical details.
