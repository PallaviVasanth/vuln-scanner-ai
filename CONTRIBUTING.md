\# Contributing



Thank you for your interest in contributing to vuln-scanner-ai.



\## Getting Started



1\. Fork the repository.

2\. Clone your fork.

3\. Create a new branch.

4\. Install the dependencies.

5\. Make your changes.

6\. Add or update tests.

7\. Run the test suite.

8\. Open a pull request.



\## Guidelines



\- Keep changes focused and easy to review.

\- Follow existing Python conventions.

\- Add tests for new scanner rules.

\- Never commit secrets or credentials.

\- Update documentation when project behavior changes.



\## Pull Requests



Please explain what changed, why it changed, and how it was tested.



For security vulnerabilities, follow `SECURITY.md`.
