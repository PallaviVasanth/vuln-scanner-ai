\# vuln-scanner-ai



AI-assisted vulnerability scanning and security analysis toolkit for Python applications.



\## Overview



vuln-scanner-ai is a lightweight security analysis tool that identifies common insecure coding patterns in Python source code.



The project is designed to provide developers with fast, understandable security feedback during development.



\## Features



\- Hardcoded secret detection

\- Dangerous `eval()` detection

\- Debug mode detection

\- Weak MD5 hashing detection

\- Severity classification

\- Line-level findings

\- Automated tests

\- GitHub Actions CI
